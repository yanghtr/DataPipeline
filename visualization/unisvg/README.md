# UniSVG 实验结果对比可视化

多列对比查看 SVG 生成实验的结果。每列展示三层内容：预渲染图片、SVG 源码、浏览器实时渲染。

## 目录结构假设

每个实验结果目录包含如下文件（index 一一对应）：

```
/path/to/exp1/
  gt_0.svg    gt_0.png
  gt_1.svg    gt_1.png
  ...
  gen_0.svg   gen_0.png
  gen_1.svg   gen_1.png
  ...
```

- `gt_*` 文件为 Ground Truth，各实验目录内容相同，**取第一个目录的 GT**。
- `gen_*` 文件为各实验的生成结果，每个目录各自独立。

## 启动

```bash
# 对比两个实验目录
python visualization/unisvg/viewer.py \
    --dirs /path/to/exp1 /path/to/exp2 \
    --port 7862

# 对比三个或更多目录
python visualization/unisvg/viewer.py \
    --dirs /path/to/exp1 /path/to/exp2 /path/to/exp3 \
    --port 7862

# 仅本机访问
python visualization/unisvg/viewer.py \
    --dirs /path/to/exp1 /path/to/exp2 \
    --host 127.0.0.1 --port 7862
```

浏览器打开 `http://localhost:7862`。

## 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--dirs` | 实验结果目录路径（必填，空格分隔多个） | — |
| `--port` | HTTP 端口 | `7862` |
| `--host` | 监听地址（`0.0.0.0` 允许外网访问） | `0.0.0.0` |

## 页面布局

```
┌────┬──────────────────┬──────────────────┬──────────────────┐
│ #  │       GT         │      Exp 1       │      Exp 2       │
├────┼──────────────────┼──────────────────┼──────────────────┤
│    │ [PNG 预渲染图]   │ [PNG 预渲染图]   │ [PNG 预渲染图]   │
│ 0  ├──────────────────┼──────────────────┼──────────────────┤
│    │ [SVG 源码]       │ [SVG 源码]       │ [SVG 源码]       │
│    ├──────────────────┼──────────────────┼──────────────────┤
│    │ [实时渲染]       │ [实时渲染]       │ [实时渲染]       │
├────┼──────────────────┼──────────────────┼──────────────────┤
│    │ ...              │ ...              │ ...              │
```

- **最左列**：GT（取 `--dirs` 第一个目录的 `gt_*.svg/png`）
- **后续列**：各实验目录的 `gen_*.svg/png`（按 `--dirs` 顺序）
- 工具栏「SVG 源码」「实时渲染」按钮可整体切换对应区域的显示/隐藏
- 每个 SVG 源码区右上角有「复制」按钮
- 键盘 `←` / `→` 翻页
